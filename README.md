# Addis Bean Co. - Next.js Project

A pure **Next.js 14 App Router** application demonstrating best practices for the **IBT College • CodeOps** curriculum (Days 42-50).

## Features Implemented:
1. **Next.js App Router Setup**: Clean `src/app` architecture.
2. **Day 43 Performance**: `next/image` with proper sizing/priority, `next/font/google` for CLS prevention, strict `.env.example` setup.
3. **Day 44 Metadata**: SEO-friendly dynamic metadata.
4. **Day 46/47 UI & State**: React Context for shopping cart, zero-dependency `Intl` API formatting, URL-based category filtering.
5. **Day 48 Form Actions**: Validated checkout using `<form onSubmit>`, semantic HTML, and `type="tel"`. **No real payment endpoints used.**
